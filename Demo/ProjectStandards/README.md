# 项目标准样例

这两份 Profile 是为工具演示自行模拟的团队标准，不包含公司数据，也不声称数值适用于所有项目：

- `environment-prop-pc.v3.json`：PC 环境道具的几何、材质、碰撞、Lightmap、命名与目录政策；
- `mobile-prop-texture.v1.json`：移动端道具纹理的 2K、Mip、Texture Group、压缩色彩、VT 与流送政策。

演示时先在插件中复制同轨道内置模板，再打开“项目验收标准工作台”，参考样例调整字段并预览差异。
样例可直接复制到目标工程 `Config/AssetAudit/Profiles`，也可以只作为阈值讨论稿。
