## 截图验收

- 统一使用 16:9 或接近 16:9 的清晰画面，面板文字可读；
- 不出现个人账号、聊天窗口、密钥、无关工程路径或其他项目内容；
- 截图文件放入 `docs/images/workflow/v0.8/`，名称使用 `01-` 至 `15-` 的稳定前缀；
- README 只引用已经真实拍摄并核对当前版本的图片；
- 每次 UI 大改后重新拍摄，不沿用无法证明当前行为的旧图。

01–14 由 UE 5.8.1 独立 `-RenderOffscreen` 宿主直接调用生产 Slate 控件生成。15 使用独立浏览器打开
由真实 Unreal Report 确定性导出的单文件 HTML，并完成桌面宽度、横向溢出和控制台错误检查；它不是
Unreal 面板截图。两类证据的来源必须分开陈述。

## 仍需人工录屏覆盖的交互

自动化截图不声明鼠标操作已经通过。正式录屏仍应展示 Content Browser 多选、Profile 下拉切换、
“读取当前选择”“开始只读审计”、运行中的手动取消、历史下拉、手动比较、“导出团队包”、打开 HTML/CSV
以及外部 JSON 查看过程。
