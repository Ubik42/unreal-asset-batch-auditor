# 当前版本真实截图清单

截图必须来自当前打包版本的真实 Unreal Editor 会话。离线 fixture、UI 草图、旧版截图和合成图不能代替以下证据。

| 编号 | 场景 | 画面必须包含 | 证明内容 |
| --- | --- | --- | --- |
| 01 | 规则选择 | 三套内置 Profile 下拉项与阈值摘要 | 普通用户不需要填写 JSON 路径 |
| 02 | 批量范围 | Content Browser 多选 24 个 Demo 网格、面板显示选择数量 | 扫描范围来自显式选择 |
| 03 | 资产总览 | 通过、需处理资产混合；三角形/顶点/材质槽/LOD/Nanite 列 | 完整台账不会隐藏通过资产 |
| 04 | 问题明细 | 错误、警告、实测值、阈值和中文证据说明 | 每条结论可追溯到 Profile |
| 05 | 成功状态 | 宽松 Profile 下的通过资产与 0 问题或低问题批次 | 插件不是只会制造红色告警 |
| 06 | 失败隔离 | 同批选中 Static Mesh 与 Material，显示采集失败且其余资产完成 | 单资产失败不会拖垮整批 |
| 07 | Profile 对比 | 同一批资产切换移动端严格/宽松复核后的摘要差异 | 结论属于项目策略，不是假装行业标准 |
| 08 | 报告落盘 | 面板底栏、最新 JSON、Issue/Evidence/host version 字段 | Editor 操作形成可交接报告 |

## 截图验收

- 统一使用 16:9 或接近 16:9 的清晰画面，面板文字可读；
- 不出现个人账号、聊天窗口、密钥、无关工程路径或其他项目内容；
- 截图文件放入 `docs/images/workflow/`，名称使用 `01-` 至 `08-` 的稳定前缀；
- README 只引用已经真实拍摄并核对当前版本的图片；
- 每次 UI 大改后重新拍摄，不沿用无法证明当前行为的旧图。
