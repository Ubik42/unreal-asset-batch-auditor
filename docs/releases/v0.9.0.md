# Unreal Asset Batch Auditor v0.9.0

v0.9.0 把插件从“批量检查面板”推进成面向美术团队的资产交付验收台：人工审计、历史回归、团队交接
和无人值守门禁共用同一份项目 Profile、C++ 事实采集和 Evidence 合同。

## 本版重点

- 显式资产与 Content Browser 文件夹组成同一交付批次，递归范围只发现 Static Mesh；
- 交付风险谱按几何、材质、构建、命名路径和采集异常汇总真实 Report；
- Profile / Report v3 增加缺失材质、唯一材质、纹理依赖数和最大纹理尺寸；
- 资产台账新增“槽/材”“纹理/最大”两组可直接复核的宿主事实；
- 版本化项目预设绑定 Profile、显式范围、阻断严重度和输出位置；
- `UnrealEditor-Cmd` 无人值守入口提供 0/10/20/30/40 稳定退出语义；
- 继续保留不可变历史、修复前后回归、批次间取消和中文 HTML/CSV 团队交接包。

## 安装

本版本提供 Windows 11 + Unreal Engine 5.8.1 Win64 已编译项目插件：

```powershell
.\install-plugin.ps1 -Action Install -ProjectPath "<项目目录或 .uproject 路径>"
```

安装后入口：`工具 > 资产批量审计`。升级和可恢复卸载见随包 `README_安装说明.md`。

## 验证范围

- 73 项 Python 回归与 Ruff；
- UE 5.8.1 Win64 BuildPlugin；
- 真实 Engine Static Mesh 材质/纹理依赖采集；
- 独立隐藏宿主中的面板任务、全新安装、升级和真实单资产审计；
- 随包项目预设的独立无人值守审计；
- 相同输入两次确定性打包与 SHA-256 校验。

## 边界

- 示例 Profile 是模拟项目数据，不是行业统一标准；
- 纹理依赖来自已加载材质接口，不是完整 Cook 图、显存或 GPU 成本；
- 插件不修改资产，不自动切换 Nanite，也没有 SavePackage/MarkPackageDirty 路径；
- 只声明 Windows 11、Win64、UE 5.8.1；不声明 Marketplace 就绪或跨版本兼容；
- 自动化宿主证据不冒充人工鼠标操作，录屏用于补充可见交互展示。
