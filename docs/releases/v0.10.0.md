# Unreal Asset Batch Auditor v0.10.0

v0.10.0 把资产交付验收台从单一模型审计扩展为“模型交付 / 纹理交付”双轨工作台，并补齐从风险热区、
单项 Evidence 到人工决定和团队交接的复核路径。它仍是确定性、Profile 驱动、默认只读的 Unreal
Editor 工具，不依赖 AI 判断，也不自动修改资产。

## 本版重点

- 新增独立 Texture Profile / Report v1，不把纹理字段混入既有 Static Mesh v1/v2/v3 合同；
- C++ 批量读取 Texture2D 源/平台尺寸、Mip、Texture Group、Compression、sRGB、VT 与流送状态；
- Python 按项目 Profile 检查尺寸、2 次幂、Mip、分组、压缩/色彩组合、VT 和 Streaming；
- 原生 Slate 增加明确的验收轨道、纹理专用规则、资产列、筛选和纹理编辑器复核入口；
- 交付目录热区按失败、需修复、问题密度和问题数稳定排序，可下钻到资产与 Evidence；
- Review Ledger 记录需修复、批准例外、负责人和备注，不改写原始 Report；
- 中文 HTML、问题 CSV、目录热区 CSV 与 SHA-256 清单可交给没有 Unreal 环境的协作者；
- 继续支持不可变会话、同 Profile 回归、批次进度、批次间取消与无人值守门禁。

## 安装与入口

本包面向 Windows 11 + Unreal Engine 5.8.1 Win64 项目级安装：

```powershell
.\install-plugin.ps1 -Action Install -ProjectPath "<项目目录或 .uproject 路径>"
```

安装后从 `工具 > 资产批量审计` 打开。先选“模型交付轨道”或“纹理交付轨道”，再读取 Content
Browser 中显式选择的资产/文件夹并选择对应 Profile。插件不会默认扫描整个项目。

## 边界

- 示例 Profile 是模拟项目数据，不代表行业统一标准；
- Editor 元数据不等于最终 Cook 体积、运行时显存、Shader 或 GPU 成本；
- 插件不修改尺寸、Mip、压缩、VT、Nanite、碰撞、命名或目录；
- 只声明 Windows 11、Win64、UE 5.8.1，不声明 Marketplace 就绪或跨版本兼容；
- 自动化宿主证明可执行路径和结构化结果，不冒充人工鼠标操作或生产规模性能测试。
